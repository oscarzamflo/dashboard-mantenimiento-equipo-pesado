# dashboard-mantenimiento-equipo-pesado
Dashboard interactivo en Power BI + análisis en Python (pandas) sobre órdenes de mantenimiento de equipo pesado — KPIs de costo, tiempo de reparación y reincidencia por sector y tipo de servicio. Proyecto de portafolio con datos simulados.

Descripción

Proyecto personal de portafolio — análisis de datos y dashboard interactivo, con datos simulados de una empresa de mantenimiento de equipo pesado.

Problema que resuelve

Las empresas de mantenimiento de maquinaria pesada manejan cientos de órdenes de servicio por año, con costos, tiempos de reparación y tasas de reincidencia que varían según el tipo de servicio y el sector del cliente. Sin un seguimiento centralizado, es difícil identificar qué servicios concentran más costo, qué sectores generan más reincidencias o cómo evoluciona el gasto mes a mes. Este proyecto simula ese escenario para practicar el flujo completo de un análisis de datos: desde el dataset crudo hasta un dashboard ejecutivo que responde esas preguntas de un vistazo.

KPIs calculados
Costo Total (PEN)
N° de Órdenes
Tiempo Promedio de Reparación (horas)
Tasa de Reincidencia (%)
Costo total y tiempo promedio por tipo de servicio
Costo total y reincidencia por sector de cliente
Desempeño por técnico responsable (N° órdenes, costo promedio, reincidencia)
Matriz cruzada sector de cliente x tipo de servicio (costo total, con mapa de calor)
Tendencia mensual del costo total
